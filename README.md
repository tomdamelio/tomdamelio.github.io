# tomasdamelio.com

Source for my personal website: research, publications, and industry work at the intersection of neuroscience, mathematics and machine learning.

**[tomasdamelio.com](https://tomasdamelio.com)**

## Structure

- `_pages/` — site pages (about, research, industry, community)
- `_projects/` — industry project write-ups
- `_community_building/` — community project write-ups
- `_bibliography/papers.bib` — publications, rendered from BibTeX
- `_news/` — homepage announcements

## Built with

[Jekyll](https://jekyllrb.com/) and the [al-folio](https://github.com/alshedivat/al-folio) theme. See [LICENSE](LICENSE) for the theme's MIT license.
